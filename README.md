# 현장 날씨 감시 (`weather.py`)
기상청 날씨누리에서 **포항시 남구 송도동** 현재 날씨를 읽어, 콘솔에 보여 주고 `weather.json`에 시간대별로 남기는 프로그램입니다.

## 만든 목적
건설 현장에서 날씨·체감온도·대기질·특보를 한눈에 보기 위함.

- 홈페이지를 매번 열지 않아도 같은 화면에서 값이 갱신됩니다.` --headless `이용으로 창이 뜨진 않습니다. 창을 따로 띄우고 싶다면 47번 줄을 주석 처리 합니다.
- 체감온도로 폭염 단계를 나눠, 더위 위험을 바로 알 수 있습니다.
- 한 시간마다 값을 파일에 남겨, 나중에 그날 날씨를 다시 볼 수 있습니다.

## 작동 방식
1. **숨긴 크롬(Selenium)** 으로 기상청 페이지를 엽니다.
2. 개발자 도구에서 복사한 **XPath**로 온도, 체감, 습도, 바람, 강수, 특보, 대기질, 일출·일몰, 지역 이름을 읽습니다.
3. 날씨(맑음/흐림 등)는 글자가 아니라 아이콘인 경우가 많아서, 예보표의 **1시간 간격** 칸에서 읽습니다. 9시 38분이면 `09시` 예보를 씁니다.
4. **1초마다** 콘솔의 같은 줄을 지우고 다시 출력합니다. 홈페이지는 **60초마다** 새로고침합니다.
5. 날씨·온도·체감·습도·풍속·강수가 모두 들어오면 `weather.json`에 저장합니다. **지금 시각의 시(09시, 10시, …)** 칸만 덮어쓰고, 다른 시간은 그대로 둡니다. 날짜가 바뀌면 어제 기록은 버리고 오늘부터 다시 채웁니다.

값이 바뀌지 않으면 파일을 다시 쓰지 않습니다. 파일 경로는 `weather.py`와 **같은 폴더**입니다.

```text
SAVE_PATH = os.path.join(os.path.dirname(os.path.abspath(__file__)), "weather.json")
```

## 폭염 경고 (체감온도 기준)
기온이 아니라 **체감온도** 숫자로 단계를 정합니다. 높은 단계부터 적용합니다.

| 체감온도 | 표시 |
|---|---|
| 31도 이상 | 관심 |
| 33도 이상 | 폭염주의 |
| 35도 이상 | 폭염경보 |
| 38도 이상 | 위험(중대경보) |
| 그 미만 | `--` |

## `weather.json` 모양
```json
{
  "날짜": "2026-10-06",
  "09시": {
    "날씨": "흐림",
    "온도": "21.7°C",
    "체감온도": "체감(21.7°C)",
    "습도": "64%",
    "풍속": "북동3.9m/s",
    "강수": "-mm",
    "폭염": "--"
  },
  "10시": {}
}
```

`00시`부터 `23시`까지 칸이 있고, 아직 지나지 않은 시간은 `{}`입니다.

## 실행 방식
```bash
pip install selenium
python weather.py
```
끝내려면 `Ctrl+C`를 누릅니다.

다른 동을 보려면 `weather.py` 맨 위 `URL`을 그 지역 날씨누리 주소로 바꾸면 됩니다.
