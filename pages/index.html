이 폴더는?

관제 시스템에 필요한 화면을 기능별로 하나씩 나눠 만든 예시입니다. 디자인은 dashboard.html 을 그대로 따랐고, 숫자와 이름은 모두 가짜 예시입니다. 아직 데이터베이스가 없어서 저장 · 삭제 버튼은 안내 문구만 뜹니다. 대신 버튼 · 표의 줄 · 카메라 화면을 누르면 실제로 다음 화면으로 넘어갑니다.

화면 번호 읽는 법

2-1 = 2번 기능(이벤트 로그)의 1번째 화면. 모든 화면 위쪽 제목 칸 왼쪽에 이 번호가 있고, 오른쪽 탭으로 같은 기능의 다른 화면으로 옮겨 갑니다. 회의할 때 "2-1 화면의 검색 조건에 담당자도 넣자"처럼 번호로 말하면 됩니다.
