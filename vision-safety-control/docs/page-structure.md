# 비전AI 안전관제 페이지 구성 (1차)

## 관리자용
- 회원 목록(CRUD)
  - 회원가입 승인
  - 회원정보 수정(권한 설정)
  - 조직, 부서 구조 관리
- 카메라 관리
  - 카메라 목록
  - 카메라 등록 및 수정
  - 카메라 배치도
- 알림 규칙
  - 판정 기준(confidence)
  - 심각도 기준(기본값)
  - 알림 (후순위)****

## 메인
- 비로그인 메인(로그인창)
- 회원가입

## 안전관리자용 업무
- 현장작업자 CRUD
- 작업자 특별관리 지정
- 작업 등록 및 배정(CRUD)
- 장비 등록 및 배정(CRUD)

## 장비 현황(중장비, 일일 수동 업데이트)
- 장비 목록
- 장비 상세

## 관제화면(로그인 시)
- 4분할 관제 CCTV화면 (중앙) > 클릭시 단일 카메라 확대
  - 실시간 알림 패널(버튼을 만들고 팝업 형식으로 뜨게끔)
- TC/작업구역(우상단)
- CCTV 섹터 감지경보(우중앙)
- 특별관리근로자 출력 패널(우하단, ^ 아이콘을 클릭하면 나오게)
- 날씨 패널(우상단 헤더에 작게)

## 구역 및 작업
- 전체 구역 표시
  - 구역별 작업 목록
    - 작업별 작업자 목록
  - 구역별 투입장비 목록

## 이벤트 로그 & 상세
- 이벤트 목록
  - 하나의 이벤트 상세
    - 스냅샷 조회 및 저장
    - 처리 기록
  - 내보내기(목록 화면 버튼)

## 통계
- 요약
- 추이 차트
- 리포트
