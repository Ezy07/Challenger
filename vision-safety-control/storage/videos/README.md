# 시연 · 개발용 영상 폴더

실제 카메라가 없을 때 쓰는 영상 파일을 여기에 넣습니다. (영상 파일은 git 에 올라가지 않습니다)

1. 영상 파일(`.mp4` 등)을 이 폴더에 복사합니다. 하위 폴더 없이 바로 넣습니다.
2. 화면의 **카메라 등록 및 수정**에서 영상 소스를 `영상 파일`로 바꾸고 파일을 고릅니다.
3. 관제화면의 그 카메라 칸에서 영상이 반복 재생됩니다.

카메라의 `stream_url` 에는 `videos/파일이름.mp4` 로 저장됩니다.
YOLO 탐지 프로그램은 `storage/` 폴더 기준으로 이 경로를 열면 됩니다. (RTSP 주소와 똑같이 `cv2.VideoCapture()` 에 넘기면 됨)

## 브라우저에서 안 보일 때
관제화면(브라우저)은 **H.264** 영상만 어느 PC에서나 재생됩니다.
H.265(HEVC) 영상은 그래픽카드가 지원하는 PC에서만 보이니, 아래처럼 H.264 로 바꿔 넣으세요. (YOLO 는 H.265 도 읽음)

```
ffmpeg -i 원본.mp4 -c:v libx264 -crf 23 -preset fast -an -movflags +faststart 바꾼파일.mp4
```
